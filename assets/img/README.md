# Put your photos in this folder

Use these exact filenames — the site picks them up automatically. Anything not
here yet falls back to placeholder artwork, so nothing looks broken in the meantime.

```
hero.jpg            wide shot behind the headline (2000x1200+)
why.jpg             tall portrait, someone working (4:5)
cta.jpg             wide shot for the bottom call band

ba-1-before.jpg     before/after pair #1  (4:3, same angle for both)
ba-1-after.jpg
ba-2-before.jpg     pair #2
ba-2-after.jpg
ba-3-before.jpg     pair #3
ba-3-after.jpg
ba-4-before.jpg     pair #4
ba-4-after.jpg
ba-5-before.jpg     pair #5
ba-5-after.jpg
ba-6-before.jpg     pair #6
ba-6-after.jpg
```

Shoot before/after pairs from the same spot, same height, same zoom. The slider
wipes one image over the other, so a matched angle is what sells it.

Resize to about 2000px on the long edge and save at ~80% JPEG quality — big
enough to look sharp, small enough to load fast.

Captions for each pair live in the `PROJECTS` list in `main.js`.
